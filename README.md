# Active-Directory-IAM-setup-for-Goldcorp-
This repository shows the step-by-step process of how I set up **Active Directory Domain Services (AD DS)** in a virtual lab environment to implement **Identity and Access Management (IAM)**.  

It includes:  
- Installing and configuring a **Domain Controller**  
- Creating **Organizational Units (OUs)** for company branches  
- Setting up **groups** for departments (Sales, IT, HR)  
- Adding users and assigning them to groups  
- Applying **Group Policy Objects (GPOs)** to enforce access restrictions  
- Testing and validating IAM governance  

This project demonstrates how centralized IAM can be achieved using Active Directory in a simulated enterprise environment.
